# エンドレスガーデン（RogueLike）

見下ろしアイソメ（2.5D）のアクションハクスラ RPG。職業はなく、ステ振りと「武器をまたいだスキル取得」でビルドを作ります。
**オンライン専用のゲーム** です。サーバー（Cloudflare Workers ＋ Durable Objects ＋ D1）が判定とセーブを持ち、PC とスマホから同じ世界で一緒に遊べます。
パーティ・チャット・救援・ビルド閲覧・ギルド・取引所・露店・郵便受けがあります。

**https://mikado420.github.io/RogueLike/** （PC・スマホ）

---

## 遊び方

### はじめに

1. タイトルで「はじめる」（ゲストのアカウントができ、この端末に鍵が保存されます）→「あたらしく」→ 名前と色を決めて「はじめる」
   - 別の端末へ移すとき：前の端末の「アカウント」→「引き継ぎコード」を出し、新しい端末のタイトルで「引き継ぎ」に入れる
   - オフライン版のセーブ（このブラウザの保存か、書き出したファイル）は「アカウント」→「データ引き継ぎ」で1回だけ取り込める
   - 「アカウント」で ID（英数字・重複不可）と名前を登録すると、招待や個人チャットで探してもらえる
2. 最初は **翠風の草原** の入口に立っています。右上のチュートリアルの順に進めます
   - 移動 → 攻撃 → 回避 → スキルを覚える（メニュー → スキル）→ スキルを使う → ステ振り（メニュー → ステータス）→ 装備（もらった装備をメニュー → 持ち物で付ける）→ 西の出口から街へ
   - 終わるとゴールド・回復薬・封晶石がもらえます。「スキップ」でいつでも飛ばせます
3. 街 **結晶の街ルミナ** には道具屋・鍛冶屋・倉庫番・掲示板・転生の神官・記憶の泉・転送陣・拠点の管理人がいます

### 基本の流れ

- フィールドで魔物を倒して経験値・ゴールド・装備・素材を集める → レベルが上がったらステとスキルに振る
- 装備を精錬・結晶で強くし、鍛冶で作り、錬成でオプションを整える
- フィールドの奥のダンジョン、無限の塔、レイドに挑む。侵攻イベントで街を守る
- 上限 Lv100 に届いたら転生（Lv1 に戻る代わりに、ボーナスのポイント・経験値・称号）

### 操作

| 操作 | PC（初期設定） | スマホ |
| --- | --- | --- |
| 移動 | WASD／矢印キー | 左下の仮想スティック |
| 通常攻撃（押しっぱなしで連続） | J／Enter／左クリック | 攻撃ボタン |
| スキル1〜4 | 1〜4（U・I・O・P でも可）、スキル1は右クリックでも | スキルボタン |
| 回避 | Space／Shift／K | 回避ボタン |
| 調べる・話す | E／F | 調べるボタン（近くにあるときだけ出る） |
| 回復薬 | Q | 薬ボタン |
| 捕獲（封晶石） | C | 捕獲ボタン |
| チャット | T | 右上「チャット」 |
| メニュー／閉じる | M／Tab／Esc | 右上「メニュー」／× |

- キーは **メニュー → 設定 → キー割り当て** で変えられます（押したキーに置き換わり、ほかの操作と重なったキーは外れます）
- 狙いは、マウスを動かしていればマウスの方向、そうでなければ近くの敵に自動で向きます

## システム一覧

### 成長

- **レベル**：上限 100。必要経験値は `(8 + 0.15×Lv) × (10 + 2×Lv^1.3)`。格上を倒すと少し多く、5 Lv 以上格下は減る
- **ステ振り**：STR・INT・VIT・AGI・DEX に、1 Lv ごとに 3 ポイント（最初 5）。上限 255
- **個性ステ**：CRT（会心）・TEC（ブレイク・状態異常・スキル威力）・LUK（ドロップ・レア・ゴールド）・MTL（MP・耐性・回復）から1つ
- **スキル**：10 武器のツリー＋汎用 4 系統（魔法・支援・生存・武術）、全 119 スキル。前提スキルと段（Lv 1/8/18/30/45/60 で解放）がある。武器ごとにスキル枠 4 つ
- **振り直し**（記憶の泉）：`300 + 40×Lv` ゴールド。**ビルド保存** 3 枠（ステ・スキル・装備をまとめて切り替え）
- **転生**（転生の神官）：Lv100 で。Lv1 に戻り、1 回ごとにステ +15・スキル +3・経験値 +10%。最大 10 回、回数で称号

### 武器（10種）

| 武器 | 仕組み |
| --- | --- |
| 片手剣 | 盾で受ける（ガード） |
| 両手剣 | 溜め（長押しで段階が上がり威力が増す） |
| 双剣 | 多段ヒットと回避からの連撃 |
| 槍 | 間合い（先端で当てると強い） |
| 弓 | 長射程・貫通 |
| 杖 | 魔法弾・属性魔法 |
| 手甲 | コンボ（当て続けると段が上がる） |
| 銃 | 弾数とリロード・背面撃ちで強い |
| 鎌 | 広い範囲と HP 吸収 |
| 楽器 | リズム（拍に合わせると強い・味方強化） |

`npm run balance` で、武器ごとの DPS（Lv30/60/100・1体/3体）を本物の `step()` で測った表が出ます。

### 戦闘

- **ダメージ**：`攻撃力 × 威力 × K/(K+防御) × 属性 × 与ダメ%/被ダメ% × 環境 × ばらつき(±10%) × 会心`。K は `40 + 2.4×攻撃側Lv`
- **属性**：火→風→地→水→火 の4すくみ（有利 1.25 倍／不利 0.75 倍）、光⇔闇は互いに 1.25 倍、無属性は 1.0。天候と夜で属性の強さが変わる
- **会心**：率 5% + DEX×0.04% + 個性・装備。倍率 150% + STR×0.06%
- **回避**：スタミナ 30、0.35 秒無敵
- **状態異常**：燃焼・毒・出血（継続ダメージ）、凍結・スタン（行動不能）、感電、暗闇（命中低下）、鈍足、衰弱
- **ブレイク**：怯みゲージを削り切ると一定時間動けず、被ダメ +25%
- **ボス**：赤い予兆つきの範囲攻撃、フェーズ、手下召喚、シールド、安全地帯、時間切れの激昂

### 装備とハクスラ

- **部位**：武器・サブ武器（盾・矢筒・魔導書・短剣・拡張弾倉・護符）・体・頭・装飾
- **レアリティ**：コモン／レア／エピック／レジェンド／ミシック。オプション数・結晶枠・数値倍率が変わる
- **オプション** 50 種、**レジェンド固有効果** 16 種、**ミシック**（スキルが変化）7 種、**セット装備** 5 種（2・4 部位）
- **精錬** +1〜+15：+6 以上は失敗で 1 段下がる。失敗ごとに成功率が上がる天井つき
- **結晶** 11 種：枠に差し込む。外すと壊れる（ゴールドを払うと回収できる）
- **アバター**：手に入れた見た目を登録して選べる
- **ルートフィルター**（非表示・自動売却）、並べ替え、**倉庫**（アカウント共有・拡張）

### 世界

- 街 2：結晶の街ルミナ（Lv1〜）、前線の村エンバー（Lv30〜）
- フィールド 5：翠風の草原（1〜14）・蒼雫の湖沼（14〜32）・紅蓮の火山（32〜55）・黄昏の古森（52〜76）・白銀の雪原（74〜100）。シード固定の自動生成。出口で隣へ、転送陣で行ったことのある街へ
- **昼夜**：1日＝現実 1 時間。夜は暗く、視界が狭く、夜だけの魔物が出る
- **天候**：晴・雨・嵐・霧・雪・熱波、まれに極光・紅い月。10 分ごとに変わり、掲示板で予報が見られる
- **フィールドボス**：15 分ごとに湧く
- モンスター 43 種

### コンテンツ

- **ランダムダンジョン** 5 つ（各フィールドの入口から）。入るたびに地形が変わる。難易度 ノーマル／ハード／ナイトメア／アルティメット
- **無限の塔**：階ごとに強くなり、10 階ごとにボス。最高到達と 10 階ごとの途中から再開
- **レイド**「結晶の巨神」
- **侵攻イベント**：30 分ごとに 5 分、ルミナに魔物の群れ。貢献度で報酬
- **ミッション**：日替わり 3・週替わり 3
- **タイムアタック**：ダンジョン×難易度ごとの自己ベスト
- **拠点**：施設 6 種を建てると補正。維持費が要る
- **図鑑**（達成率でステボーナス）・**実績** 21・**称号** 23

### 生産と経済

- **採集**：採掘・採取・伐採・釣り。天候・夜だけの素材がある
- **サブ職** 4 種（採集・鍛冶・料理・錬成）、上限 Lv50
- **鍛冶**：段×部位を選んで作る（オプションはランダム）
- **錬成**：オプションの付け替え・数値の振り直し
- **料理**：時間制のバフ食
- ゴールドの使い道：精錬・結晶回収・振り直し・転送・倉庫拡張・拠点・鍛冶・料理・錬成
- 取引属性：取引可／一度だけ（精錬済み）／不可（レイド・塔 50 階以上の報酬）。段階3の取引所で使う

### ペット

- 弱らせた魔物（HP 35% 以下）に封晶石を使って捕獲。成功率は残り HP・レベル差・精鋭で変わる。ボスは不可。最大 20 匹
- 役割：**戦闘**（ついてきて攻撃・回復・鼓舞）／**採集**（採集量アップ・拾い物）
- 持ち主の経験値の半分で育つ。スキル 12 種から最大 3 つ。**継承**（素材のペットのスキルを1つ受け継ぐ）

### 設定とセーブ

- **設定**（メニュー → 設定）：ダメージ表示（全部／自分／合計）・効果音・画面の揺れ・画質（高／低）・音量（全体／効果音／BGM）・キー割り当て・タイトルへ
- **セーブはサーバー**：1 分ごと、エリア移動・ログアウト・切断のとき、大事な操作（精錬・生産・レベルアップ・取引など）のあとすぐ。端末に残るのはログインの鍵だけ
- 切れても自動でつなぎ直し、20 秒以内なら同じ場所に戻ります
- 同じアカウントで別の端末から入ると、前の端末は切れます（保存してから）

### 人と遊ぶ（メニュー → オンライン、チャット欄）

- **チャット**：全体・エリア・パーティ・ギルド・個人。スタンプ・エモート。名前を押すと個人あて・ブロック・通報。PC は T で入力
- **パーティ**：最大 4 人。ID で招待、募集の掲示板（行き先を選んで「募集する」→ 誰でも入れる）。近くの仲間と経験値を分け合い（人数ぶん少し増える）、ドロップは順番に配られる。入口からダンジョン・塔・レイドに入ると近くの仲間も一緒に入る。レイドのボスは入った人数で強くなる
- **自動マッチング**：ダンジョンの入口で「マッチング」→ 4 人そろうか 20 秒たって 2 人以上いれば、一緒に同じダンジョンへ
- **救援**：ダンジョン・塔・レイドの中で「救援を呼ぶ」→ 一覧に出て、ほかの人が「行く」で同じ場所へ。クリアすると助けた人にも報酬
- **ビルド閲覧**：プロフィールカード（ステ振り・スキル・装備・称号）を公開・ギルドだけ・非公開から選ぶ。名前か ID で探せる
- **ギルド**：作る・ID で招待・役職（マスター／幹部／メンバー）・抜ける・外す。拠点はギルドの共有になる
- **取引所**：持ち物の装備を値段をつけて出品（72 時間）。部位・レアリティ・オプション・上限の値段で探して買う。手数料 5%。取引不可の装備は出せず、「一度だけ」の装備は売れたら取引不可になる
- **露店**：街の中で、持ち物を並べて店を開く（手数料 2%）。遊んでいる間だけ開いていて、閉じるか街を出ると残りは郵便受けに戻る
- **郵便受け**：売上・落札品・返品・侵攻の報酬などが届く。遊んでいる間は自動で受け取る
- **世界の共有**：昼夜・天候はサーバーの時刻で全員同じ。侵攻はチャンネルをまたいだ貢献度の合計で、終わると貢献した全員の郵便受けに報酬。フィールドボスはどこかで倒されるとその区切りは全チャンネルから去る。レア天候・侵攻・ミシックのドロップは全員に通知。タイムアタックはサーバーのランキング

## data/ の編集ガイド

数値・係数・文言はほぼすべて `data/*.json` にあります。コードを触らずに調整できます。

| ファイル | 中身 |
| --- | --- |
| `balance.json` | 全体の係数（tick 数、ダメージ式、ステの効き、経験値曲線、振り直し・転生、プレイヤー・モンスターの基本値、ドロップ、売値、開始時の持ち物） |
| `weapons.json` | 武器 10 種（ステの効き方、通常攻撃、仕組みの数値） |
| `skills.json` | 全スキル（武器・段・前提・最大 Lv・威力・範囲・MP・クールダウン・状態異常） |
| `statuses.json` | 状態異常・バフの効果と時間 |
| `monsters.json` | モンスター（属性・形・色・技・耐性・ドロップ表・捕獲可否） |
| `equipment.json` / `rarities.json` / `options.json` | 装備の土台・レアリティ・ランダムオプション |
| `uniques.json` / `mythics.json` / `sets.json` / `crystals.json` | 固有効果・ミシック・セット・結晶 |
| `refine.json` / `storage.json` / `looks.json` | 精錬の確率と費用・倉庫・見た目 |
| `drops.json` / `materials.json` | ドロップ表・素材と消耗品 |
| `areas.json` / `maps/` / `tiles.json` / `palettes.json` | エリア（Lv・出る魔物・出口・自動生成の設定）・手作りマップ・タイル・色 |
| `npcs.json` / `shops.json` | NPC と店の品ぞろえ |
| `time.json` / `weather.json` / `ambience.json` / `music.json` | 昼夜・天候・画面の色味と粒・BGM の選び方と曲 |
| `dungeons.json` / `difficulties.json` / `tower.json` / `raid.json` / `invasion.json` | ダンジョン・難易度・塔・レイド・侵攻 |
| `missions.json` / `achievements.json` / `titles.json` / `codex.json` / `base.json` | ミッション・実績・称号・図鑑・拠点 |
| `gathering.json` / `subjobs.json` / `recipes.json` | 採集・サブ職・鍛冶／料理／錬成のレシピ |
| `pets.json` | 捕獲率・ペットの成長・スキル |
| `tutorial.json` | チュートリアルの段（種類・回数・名前・表示するキー）と報酬 |
| `text.json` | 画面の文言（`txt(key)` で引く） |
| `balance_check.json` | `npm run balance` の目安（武器 DPS の許容幅など） |

**例**

- 経験値を 2 倍にしたい → `balance.json` の `progression.expMonster` の先頭 2 つを 2 倍
- 新しい魔物を足す → `monsters.json` に1つ足し、`areas.json` の出したいエリアの `monsters` に id を足す
- スキルの威力を変える → `skills.json` の `skills` にある該当スキルの `attack.power`（`[Lv1 の威力, 1 Lv ごとの伸び]`）
- 文言を変える → `text.json`

編集したら `npm test` と `npm run balance` で、テストと武器の DPS・経済の表を確かめてください。

- `npm run dev:server`：サーバーを手元で（wrangler dev、http://localhost:8787）
- `npm run dev`：フロントの開発サーバー（http://localhost:5173 → 手元のサーバーにつなぐ）
  - `?lag=200&loss=0.05`：200ms の遅延と 5% の取りこぼしを入れて遊ぶ
  - `?local=1`：サーバーなしで、ブラウザの中の疑似サーバーでひとりで（開発用。本番のビルドには出ない）
- `npm test`：shared の単体テストと、サーバーの結合テスト（Node の中の疑似 Cloudflare：DO・D1（node:sqlite）・WebSocket）。アイテムとゴールドが増えも消えもしないことも確かめる
- `npm run balance`：武器ごとの DPS 表と経済の表
- `npm run loadtest`：ボットで負荷を測り、無料枠の見積もりを出す（`docs/COST.md`）
- `npm run build`：型チェック（フロント・サーバー）して `dist/` に出力

`main` に push すると `.github/workflows/deploy.yml` がテスト → Cloudflare Workers（サーバー）と GitHub Pages（フロント）のデプロイを行います。
サーバーの準備（Cloudflare のアカウント・API トークン・D1・GitHub の Secrets）は **`docs/SETUP.md`**。無料枠の見積もりは **`docs/COST.md`**。

## 構成

```
ブラウザ（GitHub Pages）
  │  HTTP：ログイン・キャラ・取引所の検索・パーティ・ギルド…
  │  WebSocket：ゲーム（入力 → 差分スナップショット）、チャット
  ▼
Worker（入口）── チケット（HMAC 署名）を確かめて振り分ける
  ├─ AreaDO        街・フィールド1つ×チャンネル1つ。中で shared の step() を回す。30 人を超えたら次のチャンネル
  ├─ InstanceDO    ダンジョン・塔・レイド（パーティごと。誰もいなくなったら消える）
  ├─ AccountDO     アカウントごと。キャラ・持ち物・倉庫・ゴールドの「正」。郵便受け。二重ログインの防止
  ├─ WorldDO       全体で1つ。チャンネルの割り当て・ワールド通知・侵攻とフィールドボスの集計・救援・募集・マッチング・ランキングのまとめ書き
  ├─ ChatDO        全体チャンネルと、人ごとの受け口（休止つき WebSocket）
  ├─ PartyDO / GuildDO / MarketDO
  └─ D1            名前と ID・引き継ぎコード・公開ビルド・ランキング・ギルド名・通報・停止
```

- 判定はすべてサーバー。client は入力（移動・狙い・攻撃・スキル・回避・調べる・コマンド）に連番をつけて送り、受け取った差分を描くだけ。自分の動きは先に動かして、ずれたら直す。ほかの人と魔物は少し前の時刻で補間
- エリアに入ると AreaDO が AccountDO からアカウントの写しをもらい（世代つき）、1 分ごと・移動・ログアウトで書き戻す。古い世代の書き戻しは断るので、二重ログインでも増えない
- 取引の受け渡しは必ず AccountDO を通す：出す側を「書き戻し＋待ちの取引」の1回の書き込みで減らし、受け取る側の郵便受けに番号つきで届ける（同じ番号は1回だけ。届くまで送り直す）

## ディレクトリ構成

```
client/        ブラウザ側（PixiJS v8 の描画・入力・UI・音）
  src/main.ts      起動・タイトル（ログイン）
  src/game.ts      ループ・描画・UI のまとめ
  src/net/         api（HTTP）・transport（WebSocket・遅延の再現）・session（予測と補間・再接続）・social（チャット）・online（窓口の実装）
  src/view.ts      アイソメ描画・名前・露店の看板
  src/hud.ts       バー・スキルボタン・仮想スティック・通知・チュートリアル・接続の状態
  src/ui/          メニュー・NPC の画面・タイトル・オンラインのタブ・チャット欄・データ引き継ぎ
shared/        サーバーとテストの両方で動くロジック（DOM・PixiJS・window に依存しない）
  src/systems/     world（step）… social（パーティの分配・会話）・trade（取引所・露店・郵便受け）など
  src/host/        AreaHost（エリア1つ）・LocalServer（ローカル疑似サーバー）・Bot・イベントの宛先
  src/net/         通信の型・差分スナップショット・描くための写し・チャットの型・開発用の LocalHub
  src/validate.ts  オフライン版のセーブの検証
  src/online.ts    オンライン用の窓口の型
server/        Cloudflare Workers
  wrangler.jsonc   Worker・DO・D1 の設定
  config.json      tick・送信頻度・人数・関心範囲などの設定（無料枠対策）
  migrations/      D1 のスキーマ
  src/index.ts     Worker（HTTP API・WebSocket の振り分け・管理用 API）
  src/do/          AreaDO・InstanceDO・AccountDO・WorldDO・ChatDO・PartyDO・GuildDO・MarketDO
  test/            結合テスト（疑似 Cloudflare・テスト用の client）
data/          JSON（数値・係数・文言）。social.json（パーティ・チャット・救援・ギルド）・market.json（取引）
scripts/       balance.ts・economy.ts・loadtest.ts
docs/          PROGRESS.md（オフライン版）・PROGRESS-ONLINE.md（オンライン化）・SETUP.md・COST.md
```

### 設計の約束

- 判定・計算はすべて `/shared` の純粋な関数。サーバー（AreaDO）とテスト（LocalServer）が同じ `step()` を回す
- 1 エリア＝1 ワールド。エリア移動は「取り出す（`removePlayer`）→ 入れる（`addPlayer`）」。step は移動せず、`p.transition` をホストが処理する
- `GameEvent` は `playerId` があれば本人だけ、なければエリアの全員に届く
- 乱数はすべてシード付き。アイテムの uid はワールドごとの乱数で 52bit
- セーブの形を変えたら `SAVE_VERSION` を上げて `MIGRATIONS` に変換を足す

### 管理用 API

ヘッダー `x-admin-token: <ADMIN_TOKEN>` をつけて呼ぶ。

| | |
| --- | --- |
| `POST /admin/notice` `{text}` | 全員にお知らせ |
| `POST /admin/ban` `{accountId, reason, hours}` / `POST /admin/unban` `{accountId}` | 停止（遊んでいれば切れる）・解除 |
| `GET /admin/logs?kind=cheat|report` | 不正の疑い・通報の記録 |
| `GET /admin/stats` | 遊んでいる人数・エリアごとの人数・チャットの接続数・取引所 |

## 仮決め

指定のなかったところは次のように決めました。数値はほぼすべて `data/` にあるので、あとで変えられます。

**成長**
- レベル上限 100、転生は最大 10 回。転生 1 回でステ +15・スキル +3・経験値 +10%
- ステは 1 Lv ごとに 3 ポイント（最初 5）、スキルは 1 Lv ごとに 1 ポイント（最初 1）。ステ上限 255
- スキルの段は Lv 1/8/18/30/45/60 で解放
- 振り直しは `300 + 40×Lv` ゴールド。ビルド保存は 3 枠
- 個性ステは振り始める前なら選び直せる。振った後は振り直しで変える

**戦闘**
- 防御の軽減は `K/(K+防御)`、K = 40 + 2.4×攻撃側の Lv（高 Lv ほど同じ防御の効きが落ちる）
- 無属性を追加（相性 1.0）。4すくみで向かい合う組（火と地、風と水）は 1.0
- 会心の基本は 5%・150%。ブレイク中は被ダメ +25%
- MP は通常攻撃を当てて溜める（時間では回復しない）。HP は戦闘から 5 秒離れると少しずつ回復
- 回避はスタミナ 30・0.35 秒無敵。スタミナは 0.6 秒後から毎秒 30 回復
- 武器を持ち替えるとクールダウンはリセット。通常攻撃と多くのスキルは近くの敵に自動で向く（スマホのため）
- 倒れると 5 秒後に、いるエリアの入口で復活。持ち物は失わない

**装備**
- 精錬は +15 まで。+6 以上は失敗で 1 段下がる。失敗 1 回ごとに成功率 +6%（成功で戻る）
- 精錬した装備は「一度だけ取引可」になる
- 結晶は外すと壊れる。ゴールドを払えば回収できる
- 持ち物 60 枠。倉庫は 40 枠から 20 枠ずつ 200 枠まで広げられる（費用は 1.6 倍ずつ）
- 落ちたアイテムは 120 秒で消える。近づくと自動で拾う

**世界とコンテンツ**
- 1日＝現実 1 時間（朝 8 時から始まる）。天候は 10 分ごと、予報は 6 区切りぶん（1 時間）先まで
- 天候と昼夜は時計とシードで決まるので、同じ時刻なら誰が見ても同じ（段階3でそのまま共有できる）
- フィールドボスは 15 分ごと。侵攻は 30 分ごとに 5 分、4 ウェーブ
- 塔は 1 階ごとに Lv +1.2、10 階ごとにボスと再開地点。50 階以上の報酬は取引不可
- 難易度：ハードは HP 1.8 倍・攻撃 1.35 倍・報酬 1.6 倍、ナイトメアとアルティメットはさらに上で専用の技がある
- 拠点の維持費は施設のレベル合計 × 600 ゴールドを現実の 1 日ごと（UTC）。払えないと補正が止まる
- 日替わり・週替わりミッションは日付（UTC）と週で内容が決まる（同じ日なら同じ）

**生産とペット**
- サブ職の上限は Lv50。足りない段のレシピは作れない
- 捕獲は HP 35% 以下で、基本 20% ＋ 減った HP ぶん − 格上のレベル差ぶん。精鋭は半分。ボスは不可
- ペットは持ち主の経験値の 50% で育ち、必要経験値はプレイヤーの 0.6 倍。最大 20 匹・スキル最大 3 つ
- 継承は `800 + 120×Lv` ゴールドで、素材のペットは消える

**チュートリアルと保存**
- 新しいキャラは最初のフィールド（翠風の草原）の街側の入口から始まる。チュートリアル済みのキャラ（古いセーブも）は今までどおり
- チュートリアルの「装備」の段で練習用のレア片手剣をもらえる。全部終えると 500 ゴールド・回復薬 5・封晶石 2
- 画質「低」は描画の解像度を 1 倍にし、天候の粒を減らす

**見た目と音**
- 見た目は図形の仮素材。`client/src/sprites.ts` のスプライト名を画像に差し替える
- 効果音と BGM は WebAudio でその場で合成（外部ファイルなし）。BGM は `data/music.json` の表で選ぶ仮の曲

**オンライン化（段階3）**
- オフライン版は廃止。オフライン版のセーブは 1 アカウント 1 回だけ取り込める。検証でおかしかったもの（data にない装備、レアリティとレベルの範囲を超えるオプションや数値、+15 を超える精錬、上限を超えるゴールド・素材、合計が合わないステ／スキルのポイントなど）は削って、何を削ったかを表示する。ステ・スキルの振り方がおかしいときは振り直し（ポイントは戻る）。キャラの上限は 4 人で、超えた分は取り込まない
- ゴールドの上限 999,999,999、素材は 1 種類 9,999 まで
- ログインはゲスト（`アカウントid.秘密` を端末に保存）。ID は英数字と _ の 3〜16 文字、大文字小文字は区別しない。引き継ぎコードは 10 文字・24 時間・1 回だけで、使うと前の端末の鍵は無効になる
- 二重ログインは「アカウント」単位（同じアカウントの別キャラでも、新しい方が入ると前の方は保存してから切れる）。倉庫を2か所から触れないようにするため
- 切断の猶予は 20 秒。そのあいだキャラはエリアに残る（倒されることもある）
- 1 エリアの人数は 30 人まで。超えたら次のチャンネル（`meadow#2` など）。チャンネルは空いているいちばん小さい番号
- 移動の途中で切れたら、次のログインは行き先から。インスタンスの中で切れて猶予を過ぎたら、次は最後の街から
- パーティ：経験値は近く（24 タイル）の仲間で `(1 + 0.2×(人数−1)) / 人数` ずつ。ドロップの持ち主は近くの仲間に順番。一緒にインスタンスに入るのは入口の近く（10 タイル）にいる仲間
- 自動マッチングは 4 人、または 20 秒待って 2 人以上で出発。マッチングの仲間は、そのインスタンスの中だけの仮のパーティ
- 救援の一覧は 15 分で消える。救援で入った人への報酬は 300 G ＋ 30 G × インスタンスのレベルと、次のレベルまでの経験値の 20%
- チャット：120 文字まで、0.8 秒に 1 回・1 分に 20 回まで。NG ワードは ＊ で伏せる（`data/social.json`）。全体と個人の会話は直近 50 件まで残る
- ギルドは 50 人まで、名前は 16 文字・重複不可。**拠点はギルドの共有**：ギルドを作った人の拠点がギルドの拠点のはじまりになる。入った人の自分の拠点はそのまま残り、ギルドに入っている間は使わない（抜けるとまた使える）。施設を建てる・維持費を払うのはエリアで（素材とゴールドは建てた人が払う）。同時に建てても2段上がらない
- 取引所の手数料は 5%（売上から引く）、出品は 1 人 20 件・72 時間まで。期限切れ・取り下げは郵便受けに戻る。露店の手数料は 2%・8 品まで
- 侵攻の報酬（ゴールド・素材・エピック）はオンラインでは郵便受けに届く（経験値の報酬はなし）
- フィールドボスはチャンネルごとに出るが、どこかで倒されたらその区切りはほかのチャンネルからも去る（倒した人だけが報酬）
- タイムアタックのランキングはダンジョン×難易度ごとに上位 10。パーティの記録は名前を「・」でつなぐ
- 不正対策：入力は 1 秒 40 回・コマンドは 1 秒 10 回まで（超えた分は捨てて記録）。移動と攻撃の間隔はサーバーが計算するので、client の値は使わない（ずれたら記録）。HTTP は同じ IP から 1 分 120 回まで
- 停止された人はログインできず、遊んでいれば切れる
