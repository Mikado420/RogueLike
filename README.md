# エンドレスガーデン（RogueLike）

見下ろしアイソメ（2.5D）のアクションハクスラMMO。職業はなく、ステ振りとスキルの横断取得でビルドを作るゲームを目指しています。
いまは **段階0（土台）〜段階1（戦闘）** までで、ブラウザの中でひとりで遊べます。

**https://mikado420.github.io/RogueLike/** （PC・スマホ）

## 遊び方

フィールドのモンスターを倒してアイテムを集めます。右下（地図の南東）の闘技場にボス「灰燼の巨獣イグナロス」がいます。

- 通常攻撃を当てると MP が溜まり、MP を使ってスキルを撃てます
- 回避ロールはスタミナを使い、短いあいだ無敵になります
- ボスの攻撃は先に赤い範囲が出ます。範囲から出るか回避で避けます
- 武器を持ち替えるとスキルも変わります（はじめから片手剣・弓・杖を持っています）
- 落ちたアイテムは近づくと拾えます。「持ち物」で確認・装備できます
- 倒れると数秒後にはじまりの場所で復活します

### 操作

| 操作 | PC | スマホ |
| --- | --- | --- |
| 移動 | WASD／矢印キー | 左下の仮想スティック |
| 通常攻撃（押しっぱなしで連続） | J／Enter／左クリック | 攻撃ボタン |
| スキル1〜4 | 1〜4（U・I・O・P でも可）、スキル1は右クリックでも | スキルボタン |
| 回避 | Space／Shift／K | 回避ボタン |
| 持ち物 | Tab／B | 右上「持ち物」 |
| 閉じる | Esc | × |

狙いは、マウスを動かしていればマウスの方向、そうでなければ近くの敵に自動で向きます。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # /shared の単体テスト（Vitest）
npm run build      # dist/ に出力
```

`main` に push すると `.github/workflows/pages.yml` がテスト → ビルド → GitHub Pages への公開を行います。
Vite の `base` は `./`（相対パス）なので、リポジトリ名に関係なく `/<リポジトリ名>/` の下で動きます。

## ディレクトリ構成

```
client/   ブラウザ側（PixiJS v8 の描画・入力・UI・効果音）
  src/main.ts     起動と固定タイムステップのループ（20tick/秒、描画は補間）
  src/input.ts    キーボード・マウス・タッチ → 「移動・狙い・攻撃・スキル1〜4・回避」に変換
  src/view.ts     アイソメ描画、奥行きソート、カメラ追従、予兆範囲、ドロップ演出
  src/fx.ts       ダメージ数字・火花・画面揺れ
  src/hud.ts      HP/MP/ST、スキルのクールダウン、仮想スティック、持ち物・設定
  src/sprites.ts  スプライト名 → 見た目（いまは図形。ここを画像に差し替える）
  src/audio.ts    jsfxr 風の効果音をその場で合成
shared/   サーバーでも動くロジック（DOM・PixiJS・window に依存しない）
  src/sim.ts      ワールドと step()。移動・当たり判定・攻撃・AI・ドロップ・復活
  src/damage.ts   ダメージ式
  src/element.ts  属性相性
  src/stats.ts    ステータス → 戦闘値
  src/loot.ts     アイテム生成・ドロップ抽選
  src/map.ts      タイルマップと当たり判定
  src/rng.ts      シード付き乱数（mulberry32）
  test/           Vitest
data/     JSON（係数・武器・スキル・モンスター・アイテム・ドロップ・レアリティ・オプション・マップ）
server/   段階3で使う（いまは予定だけ）
```

client は入力を `PlayerInput` にして `step()` に渡し、返ってきた `GameEvent` と状態を描くだけです。
戦闘の判定はすべて `/shared` の純粋な関数で行うので、段階3ではこの `step()` をそのままサーバーに移します。

## 戦闘の仕組み

- **ダメージ**：`(物理ATK or 魔法MATK) × 威力 × K/(K+防御) × 属性倍率 × ばらつき(±10%) × クリティカル倍率`（K=100、`data/balance.json`）
- **属性**：火・水・風・地・光・闇（＋無）。火→風→地→水→火 の4すくみで有利1.25倍／不利0.75倍。光⇔闇は互いに1.25倍。ほかは1.0
- **ステータス**：STR/INT/VIT/AGI/DEX＋個性ステ（いまはCRT固定）。武器ごとに ATK/MATK にどのステが効くかを `data/weapons.json` の `scaling` で決める
- **装備**：レアリティ（コモン/レア/エピック/レジェンド/ミシック）で数値倍率・ランダムオプション数（0〜4）・結晶枠（0〜2）が変わる。精錬値（+0〜+15）は1段ごとに基礎値+4%（入手時は+0）

| 名前 | 属性 | 特徴 |
| --- | --- | --- |
| スライム | 水 | 遅い体当たり |
| ホーネット | 風 | 素早い・HP低め |
| ストーンゴーレム | 地 | 硬い（魔法に弱い）・範囲の叩きつけ |
| シャドウウィスプ | 闇 | 距離をとって魔法弾 |

### ダメージ表示

- 通常：白い数字が跳ねて消える
- クリティカル：大きな黄色の数字＋画面が少し揺れる
- 弱点属性：属性色の数字＋「WEAK」
- 多段ヒット：数字を積み上げ、最後に合計（TOTAL）
- 設定の「ダメージ表示」で 全部／自分（自分が与えた分だけ）／合計（多段は合計だけ）を切り替え

## 仮決め

細かいところは次のように決めています。あとで変えられるよう、数値はほぼすべて `data/` にあります。

- **無属性**を追加した。属性のない攻撃・防御は相性1.0。プレイヤーの防御側は今は無属性
- 4すくみで向かい合う組（火と地、風と水）は1.0
- 防御の軽減は `K/(K+防御)`（K=100）。防御が0なら等倍、100なら半分
- クリティカル率 = 5% + DEX×0.2% + CRT×1% + オプション。倍率は1.5倍
- MP は最大100、自然回復なし。通常攻撃が1体以上に当たるごとに 片手剣・弓 +10／杖 +14（1振りにつき1回）
- 回避：スタミナ30消費、0.3秒移動、0.35秒無敵。スタミナは0.6秒後から毎秒30回復
- スキル枠は4つ。いまの武器のスキルは3つなので4枠目は空き
- 個性ステは今はCRTで固定（TEC/LUK/MTL は段階2で）
- ステータスは STR30 INT30 VIT20 AGI20 DEX30 CRT10 で固定（段階2でステ振り）
- 武器を持ち替えるとクールダウンはリセット
- 通常攻撃と多くのスキルは近くの敵に自動で向く（スマホで遊びやすくするため）
- アイテムは近づくと自動で拾う。持ち物は60枠。落ちたアイテムは120秒で消える
- 武器はレア以上で30%の確率で属性が付く
- モンスターは本拠地から離れすぎると戻り、戻るあいだに回復する。倒すと12〜18秒（ボスは60秒）で復活
- 倒れると5秒後にはじまりの場所で復活。持ち物は失わない
- サーバーができるまでは、ブラウザの中で `shared` のワールドを動かしている（シードは起動ごとに変わる）
- 見た目は図形の仮素材。`client/src/sprites.ts` のスプライト名を画像に差し替える
- 効果音は WebAudio でその場で合成（外部ファイルなし）
