# 進化の迷宮（RogueLike）

プレイヤー全員の狩りが魔物の進化を決める、ドット絵のオンライン・アクションハクスラです。
最大4人のパーティでローグライクなダンジョンに潜り、倒した魔物の記録が共有の生態系に送られます。
生き残った魔物が繁殖・交配・突然変異し、次の世代のダンジョンに現れます。

- 企画書：Claude のドキュメント「進化の迷宮（仮）企画書」
- 設計メモ：[docs/DESIGN.md](docs/DESIGN.md)
- 通信の約束事：[docs/PROTOCOL.md](docs/PROTOCOL.md)

## 遊び方

### オンライン（サーバーを立てる）

依存パッケージはありません。Node.js 20 以上だけで動きます。

```bash
npm start            # http://localhost:8080 （生態系は10分ごとに1世代）
npm run dev          # 生態系を60秒ごとに進める開発用
```

ブラウザで `http://localhost:8080` を開き「オンラインで遊ぶ」を選びます。
同じサーバーに別の端末からつなぐと、町で互いが見え、パーティを組めます。

| 環境変数 | 既定値 | 内容 |
| --- | --- | --- |
| `PORT` | 8080 | 待ち受けポート |
| `ECO_INTERVAL_SEC` | 600 | 生態系を1世代進める間隔（秒） |
| `DATA_FILE` | `data/world.json` | ワールドの保存先 |

### オフライン（ひとりで遊ぶ）

「ひとりで遊ぶ」を選ぶと、ブラウザの中で同じゲームが動きます。データはブラウザに保存されます。
静的ファイルとして公開すればサーバーなしで遊べます（GitHub Pages なら `/client/` を開く）。

### 操作

| 操作 | キーボード・マウス | スマホ |
| --- | --- | --- |
| 移動 | WASD／矢印 | 左のスティック |
| 攻撃 | J／Z／左クリック | 攻撃 |
| 技1（武器の技） | K／X／右クリック | 技1 |
| 技2（防具の技） | L／C | 技2 |
| 回避 | Space | 回避 |
| 調べる・階段・脱出 | E | 調べる |
| 回復薬 | Q | 薬 |

狙いはマウスの方向です。マウスを使っていないときやスマホでは、近くの敵に自動で向きます。

## ゲームの流れ

1. 町で準備（装備・工房・道具屋・取引所・図鑑・掲示板・酒場）
2. 迷宮の門から8つのエリアのどれかへ出発（ソロまたは最大4人）
3. 各階の奥に「下へ」の階段と「脱出」の魔法陣。深いほどレア素材
4. 脱出すれば素材を持ち帰り、全滅すればその回の拾い物をすべて失う
5. 倒した魔物の記録が生態系へ。次の世代の魔物が変わる

頂点捕食者が誕生すると、町の「レイドの石碑」から最大16人で挑むワールドレイドが開きます。

## フォルダ構成

```
shared/   サーバーとブラウザで共通のゲームの中身
  elements.js   属性と相性、ダメージ式
  genome.js     魔物の遺伝子（交配・突然変異・距離）
  ecosystem.js  生態系の世代計算（淘汰・繁殖・新種・絶滅・移入・頂点捕食者）
  items.js      素材・装備・技・道具
  world.js      ワールドの状態と操作（プレイヤー・工房・取引所・命名）
  dungeon.js    ダンジョン生成と当たり判定
  sim.js        戦闘シミュレーション（20回/秒）
  host.js       進行役（接続・町・パーティ・ダンジョン・レイド・時計）
  sprite.js     遺伝子から魔物のドット絵を作る
server/   Node.js サーバー（静的配信＋依存なしの WebSocket）
client/   ブラウザのゲーム（描画・入力・画面）
test/     node:test のテスト
```

## 本番で動かすとき

- `data/world.json` にワールドが保存されます。消すと世界が最初からになります。
- HTTPS で公開する場合は、前段のリバースプロキシで `/ws` を WebSocket として通してください。
- 1プロセスで動く簡易版です。人数が増えたら、ダンジョンを別プロセスに分けることを検討してください（docs/DESIGN.md）。
