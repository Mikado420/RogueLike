# 設計メモ

企画書の内容を、実装でどう決めたかの記録です。数値はすべて初期値で、遊びながら調整します。

## 決めたこと（企画書の未決事項）

| 項目 | 決定 |
| --- | --- |
| タイトル | 進化の迷宮（英題 Evolving Depths）。リポジトリ名は RogueLike |
| 世界観 | 剣と魔法のファンタジー。町の地下に、生き物のように変わり続ける迷宮が広がる |
| 課金モデル | 基本無料＋見た目の課金を想定（今回の実装には含めない） |

## 属性と相性（shared/elements.js）

- 6属性の循環：水→火→氷→風→土→雷→水。矢印の先に ×1.5、逆向きは ×0.75
- 光と闇は互いに ×1.5。同じ属性・無属性・それ以外は ×1.0
- ダメージ = 基礎攻撃力 × 相性倍率 × (1 − 耐性)。耐性は −50%〜+75%
- 湿潤の相手には雷と氷が ×1.25
- 風の種は空を飛び、氷を受けると「墜落」（1.8秒動けず、受けるダメージ +20%）
- 状態異常：火=燃焼、水=湿潤、氷=凍結、風=吹き飛ばし、土=鈍化、雷=麻痺、光=目くらまし、闇=呪い。毒は属性と無関係

## 遺伝子（shared/genome.js）

| 遺伝子 | 範囲 | 効果 |
| --- | --- | --- |
| body / atk | 8属性（atk は無属性も） | 体の属性（受ける相性）と攻撃の属性 |
| size, hp, power, speed | 0〜1 | 大きさ・HP・攻撃力・速さ |
| fecundity | 0〜1 | 繁殖力 |
| poison | 0〜1 | 0.7 超で毒持ち |
| behavior | 5種の重み | 突進・射撃・群れ・逃走・仲間呼び（最大のものが行動） |
| resist | 8属性 −0.5〜0.75 | 属性ごとの耐性 |
| parts | 整数 | 見た目（系統・頭・脚・尾・模様・目） |

## 生態系（shared/ecosystem.js）

1世代ごとに、エリアの各種について次を計算します。

1. 個体数：成長（繁殖力・種ごとの上限・エリア全体の混雑）− 自然死 − 狩られた数 − 捕食
2. 淘汰：狩りに使われた属性の割合に応じて、その属性に強い個体ほど生き残る（`exp(7 × Σ割合×耐性)`）
3. 繁殖：生き残った個体同士で交配し、突然変異を加える。個体数が少ないと変異が大きい
4. 新種：元の種の標本から遺伝子が離れた個体（距離 2.6 超）が5体以上いれば、新しい種として分かれる（エリアに最大6種）
5. 絶滅：個体数が1未満で絶滅。標本だけが図鑑に残る
6. 移入：種が少ないエリアには隣のエリアから一群が移る。空になったエリアには未知の種が湧く
7. 頂点捕食者：個体数が多い種から8世代おきに誕生。3世代以内に討伐されなければ、その系統が増える

人が少ない時期は「仮想ハンター」がランダムな属性で各種を3体ずつ狩り、変化が止まらないようにしています。
大量に狩られても一度に消えすぎないよう、狩りの影響は `n / (1 + n/40)` で頭打ちにしています。

## 装備（shared/items.js）

| 作る物 | 材料 | 受け継ぐもの |
| --- | --- | --- |
| 武器 | 牙×2 | 1つ目の牙の個体の攻撃属性、2つの力の平均。毒持ちなら毒付与 |
| 防具 | 鱗×2 | 2つの鱗の上位耐性の平均。体の属性で技2が決まる |
| 装飾品 | 核×1 | 行動パターン：突進=会心、射撃=射程、群れ=味方の耐性、逃走=移動速度、仲間呼び=吸収 |

- 武器の種類（剣・槍・弓・杖）は作るときに選ぶ。技1は武器の属性で決まる
- レア度：突然変異個体・絶滅寸前の種は★、頂点捕食者は★★
- キャラクターのレベルは HP+6・攻撃+1 のみ。強さの大部分は装備

## ダンジョンと戦闘（shared/dungeon.js, shared/sim.js）

- 1階は部屋7〜10個を通路でつなぐ。最後の部屋に階段と脱出の魔法陣
- 魔物は個体数の多い種ほど出やすく、深いほど強く（階ごとに +28%）、突然変異個体が増える
- 20回/秒で計算。当たり判定・ダメージ・ドロップはすべてここで決まり、オンラインではサーバーが行う
- ダウンから20秒以内に仲間が2.5秒そばにいれば復帰。全員ダウンで全滅
- 階段は、生きている全員が階段の上で「調べる」を押すと次の階へ
- 素材は撃破のたびに全員へ個別ドロップ（75%）

## 通信と同期（shared/host.js）

- ダンジョンの状態は 20回/秒でスナップショットを送る。クライアントは 60〜110ms 遅らせて補間する
- 自分の移動だけはクライアントで先に動かし、サーバーの位置へなめらかに寄せる
- 町の移動はクライアントが決め、位置だけを 10回/秒で共有する
- 切断したプレイヤーはその場で倒れた扱い（拾い物は失い、撃破記録は生態系に届く）
