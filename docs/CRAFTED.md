# 銘入り装備（80 品）

素材で作る、名前・部位・属性・固定の効果が決まった装備。今の鍛冶とは別に、鍛冶屋の新しいタブ「銘入り」から作る。

> 実装済み。この文書は `scripts/gen-crafted-doc.py` で組み立てています（条件を満たしているかもスクリプトで確かめています）。

## 共通のきまり

- **強さ**：レジェンド相当（基礎能力の倍率 1.48）。ランダムなのはオプションの値だけで、数はレジェンドと同じ 3 つ。ミシックには届かない。
- **固定のもの**：名前・部位・ベース・属性・固定効果・結晶スロット（序盤 1・中盤 1・最終 2）。
- **魔石は使わない**（魔石の使い道は精錬だけ）。
- **段階**：各地域で「序盤 6・中盤 6・最終 4」。ボス素材（ヒドラの牙・灰燼の鱗・竜鱗）は最終段の品だけに使う。草原はボス素材がないので嵐晶、古森は古樹の皮（エルダートレントも落とす）を最終段の核にする。
- **作れる場所**：街の鍛冶屋。鍛冶 Lv・材料・ゴールドはサーバーで確かめる。足りない材料は画面に出す。

## 決まったこと

1. **取引**：何度でも取引できる（精錬すると、今の装備と同じく「一度だけ」になる）。
2. **属性**：武器の属性は攻撃の属性になる。防具・アクセサリーは属性なし。
3. **作れる数**：同じものを何本でも作れる（オプションの値を厳選できる）。
4. **新しい条件**：溜め最大・コンボ・再装填のあと・リズム・防いだあと の 5 つと、槍の最適な間合いのダメージ（sweetDmgPct）を足した。

実装：レシピは `data/crafted.json`（このスクリプトが書き出す）。固定効果は `uniques` に `crafted.<id>` として登録し、今の効果処理を通す。作成はサーバーで材料・ゴールド・鍛冶 Lv・鍛冶屋のそばかを確かめる。
