# 銘入り装備（一覧案）

素材で作る、名前・部位・属性・固定の効果が決まった装備。今の鍛冶（ティアと部位を選ぶと、名前のない装備がランダムなレアリティで出る）とは別に、鍛冶屋の新しいタブ「銘入り」から作る。

> これは案です。確認をいただいてから実装します（data/crafted.json・鍛冶屋の画面・サーバーの検証・テスト）。

## 共通のきまり

- **強さ**：レアリティは「レジェンド相当」に固定。基礎能力はレジェンドと同じ倍率（`statMul` 1.48）で、ティアは下の表のとおり。ミシックには届かない。
- **ランダムなもの**：オプションの値だけ。オプションの数はレジェンドと同じ 3 つで、種類と値は今の生成（`loot.ts`）の仕組みで振る。
- **固定のもの**：名前・部位・ベース・属性・固定効果・結晶スロット数。
- **固定効果**：`uniques.json` と同じ形（`mods` / `when` + `whenMods` / `proc`）。強さは既存のユニーク効果と同じくらいにする。既存のユニークを流用したものは「流用」と書く。新しい種類の効果は要らない（使う効果のキーと状態異常は、すべて今の仕組みにある）。
- **作れる場所**：街の鍛冶屋。鍛冶 Lv・材料・ゴールドは、サーバーで確かめる。
- **鍛冶の経験値**：今の鍛冶 1 回と同じだけ入る（案）。
- **材料の個数**：魔石は A の供給（Lv20 で約 120 個/時、Lv100 で約 410 個/時）に合わせ、各地域の最強の装備では狩り 1〜2 時間ぶんにする。

## 条件の確かめ

- **16 種の素材**（すべて使用）：蜂の針・影の残り火・蛇の抜け殻・鰻のぬめり・ヒドラの牙・雨鱒・灰燼の鱗・炎蝙蝠の翼・地獄の牙・古樹の皮・影草・氷結核・雪男の毛・竜鱗・氷魚・嵐晶
- **10 の武器種**（それぞれ 1 つ以上）：
  - 片手剣（白銀竜の剣）、両手剣（灰燼の大剣）、双剣（蒼雫の双剣）、槍（ヒドラ牙の槍）、弓（翠風の蜂針弓）
  - 杖（黄昏の古樹杖）、手甲（嵐呼びの手甲）、銃（水妖の銃）、鎌（地獄犬の鎌）、楽器（雨鱒のリュート）
- **各地域**で、武器・防具（胴・頭・副）・アクセサリーが混ざる。ただし草原は防具が胴の 1 つだけ。
- **ボス素材**（ヒドラの牙・灰燼の鱗・古樹の皮・竜鱗）は、その地域の★の核。草原はボス素材がないので、嵐晶（嵐の日の採掘でしか出ない）を核にした。

## 決めてほしいこと

1. **取引**：作った銘入り装備は取引できるか。案は「一度だけ」（精錬済みの装備と同じ扱い）。
2. **属性の効き方**：今の装備には「属性」の項目がない。案は、武器の属性は攻撃の属性に、防具・アクセサリーの属性は表示だけにする。
3. **同じものを何本も作れるか**：案は、何本でも作れる（オプションの値がランダムなので、厳選の楽しみになる）。
